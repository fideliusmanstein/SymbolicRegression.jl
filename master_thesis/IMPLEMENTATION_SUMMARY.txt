USAGE EXAMPLES:
---------------

1. Use Savitzky-Golay differentiation:
   options = ODERegressionOptions(
       differentiation_method=:savitzky_golay,
       savitzky_golay_window=11,
       savitzky_golay_order=2
   )

2. Quick benchmark:
   include("benchmark_ode_discovery.jl")
   quick_benchmark(3)

3. Benchmark specific category:
   results = benchmark_all_problems(
       problem_filter = name -> startswith(name, "ss_"),
       save_results=true
   )

4. Compare methods on single problem:
   result_fd = benchmark_single_problem("simpleLin1", 
       ode_options=ODERegressionOptions(
           differentiation_method=:finite_difference
       ))
   
   result_sg = benchmark_single_problem("simpleLin1",
       ode_options=ODERegressionOptions(
           differentiation_method=:savitzky_golay
       ))

KEY FEATURES:
-------------

✓ Automatic equivalence detection handles:
  - Operation reordering (x+y vs y+x)
  - Constant approximations (2.0 vs 1.999)
  - Algebraic simplifications (x*2 vs 2*x)

✓ Configurable thresholds:
  - R² threshold (default: 0.95)
  - Max relative error (default: 0.1)

✓ Comprehensive output:

  - R² scores and error metrics

✓ Result persistence:
